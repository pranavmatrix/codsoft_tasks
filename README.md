# CODSOFT Cybersecurity Tasks

This repository contains cybersecurity projects completed as part of
the CODSOFT internship.

## Tasks

### Task 1 — Network Packet Analyzer

A Python and Scapy-based application that captures and analyzes network
packets.

**Technologies:** Python, Scapy

### Task 2 — Phishing Awareness Program

A web-based cybersecurity awareness module designed to educate users
about phishing attacks, social engineering, and safe security practices.

**Technologies:** HTML, CSS, JavaScript

### Task 3 — Secure Code Assessment

A Python application security assessment demonstrating common
vulnerabilities and secure coding practices.

**Technologies:** Python, SQLite
