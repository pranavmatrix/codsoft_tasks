# Phishing Awareness Program

A web-based cybersecurity awareness training module designed to
educate users about phishing attacks and common social-engineering
techniques.

## Project Objective

The objective of this project is to help users:

- Understand phishing attacks
- Identify suspicious emails
- Recognize fake login pages
- Identify fraudulent websites
- Understand social-engineering techniques
- Learn practical security practices
- Test their knowledge through an interactive quiz

## Features

### 1. Phishing Introduction

Explains what phishing is and why attackers use it.

### 2. Types of Phishing

The project explains:

- Email phishing
- Smishing
- Vishing
- Spear phishing

### 3. Warning Signs

Users learn how to recognize:

- Urgent messages
- Suspicious sender addresses
- Suspicious links
- Unexpected attachments
- Requests for passwords or authentication codes
- Unexpected payment requests

### 4. Fake Login Page

The website contains an educational mock login page demonstrating
characteristics users should examine before entering credentials.

The login form does not collect or transmit credentials.

### 5. Social Engineering

The module explains techniques involving:

- Authority
- Fear
- Urgency
- Curiosity

### 6. Case Studies

The module contains educational examples based on common phishing
and business-email-compromise scenarios.

### 7. Security Tips

Users receive practical recommendations including:

- Using multi-factor authentication
- Verifying unexpected requests
- Using unique passwords
- Keeping software updated
- Reporting suspicious messages
- Avoiding rushed decisions

### 8. Interactive Quiz

The project contains five multiple-choice questions.

The JavaScript program:

1. Collects the selected answers.
2. Checks them against the answer key.
3. Calculates the score.
4. Displays the result.
5. Provides feedback.

## Technologies Used

- HTML5
- CSS3
- JavaScript

No external frameworks or libraries are required.
